# GTM / dataLayer helpers

Use **`pushEcommerceEvent.js`** from browser code after user actions (add to cart, begin checkout) so GTM tags (Data Cloud script, MCP beacon) see consistent payloads.

Recommended event names align with [data-layer-events.schema.json](data-layer-events.schema.json); adjust to match your **Enhanced Ecommerce** or **GA4** naming in GTM.
